# CtrlKit

After Effects 上で疑似エフェクト（エフェクトコントロールにまとまって表示される自作の調整項目）を組み立て、
次の2つを書き出す ScriptUI パネルです。

- `<名前>.ffx`：疑似エフェクトのプリセット本体（リポジトリ保管用）
- `<名前>_ffx.jsx`：スクリプトに貼り付ける埋め込み用コード（`.ffx` のバイト列の文字列と、それを適用する関数）

`zabuton.jsx` と同じく、埋め込みコードは実行時に一時フォルダへ `.ffx` を書き出して `applyPreset` するので、
配布するスクリプトは `.jsx` 1つで済みます。

## 使い方

1. `ctrlkit.jsx` と `src/` フォルダを、同じ場所に置いたまま AE の `ScriptUI Panels` フォルダへコピーする
   （「ファイル > スクリプト > スクリプトファイルを実行...」で直接開いても使えます）
2. 「ウィンドウ」メニューから CtrlKit を開く
3. エフェクト名を入れ、項目を追加して名前・範囲・初期値を設定する
4. レイヤーを選んで「選択レイヤーでプレビュー」で見た目を確認する
5. 「書き出し」で `.ffx`・埋め込みコード・設定ファイル（`.ck.json`）を保存する
6. 埋め込みコードをスクリプトに貼り、`apply<名前>(layer)` を呼ぶ

「既存.ffxを変換」を使うと、手元にある `.ffx` から埋め込みコードだけを作れます。

## 対応している項目

| 種類 | 状況 |
| --- | --- |
| スライダー | 対応 |
| カラー | 対応 |
| 角度・チェックボックス・ポイント・3Dポイント・ドロップダウン・レイヤー・グループ | 見本 `.ffx` を元に対応予定 |

## 内部名（matchName）について

AE は疑似エフェクトを内部名で見分けます。内容が違うのに内部名が同じ疑似エフェクトが1つのプロジェクトに入ると、
先に読み込まれた方の定義が使われてしまいます。内部名はエフェクトごとに固有にしてください（空欄なら `Pseudo/CK <名前>`）。

## 仕組みとテスト

- `src/binary.jsxinc`：バイト列を組み立てるヘルパー（RIFX チャンク、整数、浮動小数）
- `src/ffx-writer.jsxinc`：定義から `.ffx` のバイト列を作る
- `src/embed.jsxinc`：バイト列を埋め込み用コードにする

`.ffx` の形式は公開されていないため、AE が書き出した `.ffx` を読み解いて合わせています。
`node test/run.js` で、`packages/zabuton/effectControl_zabuton.ffx` をバイト単位で再現できることなどを確認できます。
