# CtrlKit

After Effects 上で疑似エフェクト（エフェクトコントロールにまとまって表示される自作の調整項目）を組み立て、
次の2つを書き出す ScriptUI パネルです。

- `<名前>.ffx`：疑似エフェクトのプリセット本体（リポジトリ保管用）
- `<名前>_ffx.jsx`：スクリプトに貼り付ける埋め込み用コード（`.ffx` のバイト列の文字列と、それを適用する関数）

`zabuton.jsx` と同じく、埋め込みコードは実行時に一時フォルダへ `.ffx` を書き出して `applyPreset` するので、
配布するスクリプトは `.jsx` 1つで済みます。

## 使い方

1. `ctrlkit.jsx` と `src/` フォルダを、同じ場所に置いたまま AE の `ScriptUI Panels` フォルダへコピーする
   （「ファイル > スクリプト > スクリプトファイルを実行...」で直接開いても使えます）
2. 「ウィンドウ」メニューから CtrlKit を開く
3. エフェクト名を入れ、項目を追加して名前・範囲・初期値を設定する
4. 左のプレビューで並びや初期値を確認する（スライダー・チェックボックス・ドロップダウンはプレビュー上でも初期値を変えられます）
5. レイヤーを選んで「選択レイヤーにまとめて適用」で実際に付けて確認する（もう一度押すと、前に付けたものを外して付け直します）
6. 「書き出し」で `.ffx`・埋め込みコード・設定ファイル（`.ck.json`）を保存する
7. 埋め込みコードをスクリプトに貼り、`apply<名前>(layer)` を呼ぶ

「既存.ffxを変換」を使うと、手元にある `.ffx` から埋め込みコードだけを作れます。

## 対応している項目

| 種類 | 設定できること |
| --- | --- |
| スライダー | 初期値、スライダー最小／最大、有効最小／最大、小数点以下の桁数、% 表示、ピクセル値 |
| 角度 | 初期値（度。1回転 = 360） |
| チェックボックス | 初期値、横に出す文字 |
| カラー | 初期色（RGB） |
| ポイント／3Dポイント | 初期位置（レイヤーの幅・高さに対する %） |
| ドロップダウン | 項目（縦棒 \| 区切り）、初期値（1から数えた番号） |
| レイヤー | なし（初期値は「なし」） |
| ラベル | 文字を薄く表示 |
| グループ | 「グループ」と「グループ終了」の間に入れた項目がグループの中身になる |

どの項目も「非表示」を、スライダー・角度・チェックボックス・カラー・ドロップダウンは「停止キーフレーム」を設定できます。

## 内部名（matchName）について

AE は疑似エフェクトを内部名で見分けます。内容が違うのに内部名が同じ疑似エフェクトが1つのプロジェクトに入ると、
先に読み込まれた方の定義が使われてしまいます。内部名はエフェクトごとに固有にしてください（空欄なら `Pseudo/CK <名前>`）。
また AE は一度読み込んだ内部名の定義を覚えているため、項目を変えて書き出し直したときは内部名も変えてください
（プレビューでは毎回自動で別の内部名にしています）。

## 仕組みとテスト

- `src/binary.jsxinc`：バイト列を組み立てるヘルパー（RIFX チャンク、整数、浮動小数）
- `src/ffx-writer.jsxinc`：定義から `.ffx` のバイト列を作る
- `src/embed.jsxinc`：バイト列を埋め込み用コードにする

`.ffx` の形式は公開されていないため、AE が書き出した `.ffx` を読み解いて合わせています。
- `tools/build.js`：設定ファイル（`.ck.json`）から `.ffx` と埋め込みコードを作る（Node 用）
  例: `node packages/ctrlkit/tools/build.js packages/zabuton/zabuton.ck.json out.ffx out_ffx.jsx`

`node test/run.js` で、Zabuton の `.ffx` を設定ファイルから再現できることなどを確認できます。
`samples/` に見本の `.ffx` を置くと、それと同じものを作れるかも確認します（`samples/` は git の対象外）。
